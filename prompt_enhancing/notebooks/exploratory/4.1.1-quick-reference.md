# 4.1.1 Notebook Quick Reference Card

## What It Does (30-second summary)
The 4.1.1 notebook extracts structured archaeological data from PDF reports using AI. It reads scanned documents, identifies key information (dates, locations, etc.), and scores how accurately it extracted the data compared to known correct answers.

## Key Results to Look For

### 1. Overall Performance
```
Average Metric: 4.9 / 7 (70.0%)  ← 70% of fields extracted correctly
Best score so far: 80.0          ← Peak performance achieved
```

### 2. Individual Field Results  
```
✔️ [0.450] = Correct extraction, medium confidence
✔️ [0.800] = Correct extraction, high confidence  
❌ [0.000] = Failed extraction
```

### 3. Field Types & Expected Performance
- **Dates**: 70-90% accuracy (well-structured)
- **Locations**: 60-80% accuracy (variable quality)
- **Free text**: 40-70% accuracy (high variation)

## Interpreting Results

### Good Performance Indicators
- Overall accuracy >70%
- Most ✔️ symbols in results
- High confidence scores (>0.6)
- Clean visualization dashboard

### Warning Signs
- Overall accuracy <50%
- Many ❌ symbols  
- Low confidence scores (<0.3)
- Errors in MLFlow logs

### Common Issues & Solutions

| Issue | Symptoms | Solution |
|-------|----------|----------|
| Poor OCR | Low accuracy across all fields | Check source PDF quality |
| Context overflow | Truncation warnings | Adjust `_focus_and_truncate()` |
| Model overload | Timeout errors | Reduce batch size or use smaller model |
| Missing ground truth | Many NaN values | Verify dataset completeness |
